# RichInsights

**Grow. Excel.**

RichInsights is a native Android educational platform being developed by Ricven. The project is focused on creating a structured learning experience that combines study, quizzes, Bible content, current information, and other educational features in one application.

## Project

- **Product:** RichInsights
- **Platform:** Native Android
- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Package:** `com.ricven.richinsights`
- **Repository:** `ricvenlimited/richinsights-android`
- **Development direction:** V2

This repository contains the current RichInsights V2 Android application and its supporting project documentation.

## Current Direction

RichInsights is being developed as a clean V2 implementation rather than as a continuation of the earlier application. The project is being built progressively, with the Android foundation, product structure, UI/UX system, backend architecture, and future feature areas documented as development continues.

The planned product areas include:

- Home
- Learn / Study
- Quiz
- Bible
- News
- Profile

The exact implementation of individual features will continue to evolve as development progresses.

## Technology

The Android application is built natively with:

- Kotlin
- Jetpack Compose
- Android Gradle tooling

The backend direction and service architecture are documented separately and may evolve during development.
